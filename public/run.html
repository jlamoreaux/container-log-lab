Application-measured durations and process activity spans, aligned by captured timestamps. Edge, controller and process are nested; their durations are not additive. Edge ends before the KV write and the HTTP response. This is not the Cloudflare-native trace waterfall.

Readiness is time spent explicitly waiting for the container's port when its state was not healthy. Proxy overhead is proxy round-trip minus Node's process duration; it includes transport and response handling, not just startup.
