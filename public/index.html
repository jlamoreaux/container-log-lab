02 / Inspect the signals
  1. Run a scenario. Open its run detail to see the captured timeline and logs.
  2. Open the Containers dashboard. Check live container logs for the same ID.
  3. Compare Worker logs and traces. Search for the request ID, then open lab.proxy_to_process to inspect the measured phase durations.
  4. Wait one minute. Trigger another request to observe shutdown and startup events.
A note on layers

edge includes container routing but ends before KV writes; controller includes readiness and proxying; process is measured inside Node.js. These timings are nested, not additive. The run detail splits readiness from proxy overhead and shows KV write time separately. The app trace ID joins all three layers in an OTLP backend; Cloudflare's native trace is separate.
